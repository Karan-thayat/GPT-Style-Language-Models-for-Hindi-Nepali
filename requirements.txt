# Dependencies for all three phases.
#
# Note on what is deliberately absent: no HuggingFace `transformers`, and no
# pretrained tokenizer package. The project forbids pretrained models and
# tokenizers, so `sentencepiece` is used only to *train* vocabularies from
# scratch on this project's own corpora, and the Transformer is written from
# primitive PyTorch layers. `datasets` is used purely as a corpus download client.
